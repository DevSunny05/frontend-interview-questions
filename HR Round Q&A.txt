7. Describe a challenging project you worked on.

 It was a great learning experience in performance tuning and teamwork.”

or

“One of the challenging problems I solved recently was optimizing a complex dashboard in Next.js and firebase.
 The page was rendering around 4000+ records, and users were complaining about lag.
Situation: The UI froze and API response times were inconsistent.
Task: Improve performance without changing the business logic.
Action:
On the frontend, I implemented React virtualization, memoized heavy components, and reduced re-renders using useCallback and useMemo.
On the backend, I added MongoDB pagination, indexes, and optimized the aggregation pipeline.
I also introduced a debounced search, which reduced unnecessary API calls.
Result:
The page load time dropped from ~6 seconds to under 1.5 seconds. The client appreciated that the performance issue was fixed without any downtime.
This was a good example of using both frontend and backend optimizations together.”

26.6. Describe your experience handling production issues.

Answer:
“Once, a production bug occurred where users couldn’t upload images to S3 via the backend.

Steps I took:

Checked AWS CloudWatch logs, found signature mismatch.

Identified that the AWS SDK version was updated but the policy was outdated.

Rolled back the SDK version immediately to restore uploads.

Then applied a long-term fix by updating the S3 bucket policy and regenerating the IAM credentials.

Added unit tests to verify signature generation.

This prevented similar outages and ensured smooth S3 operations afterward.”
